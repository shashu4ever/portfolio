# Shashankgowda G K — Portfolio

Static portfolio (HTML + Tailwind CSS via CDN + a little JavaScript).

## Run
Open `index.html` in a browser (starry-sky hero + sections) (internet needed for Tailwind CDN and Google Fonts).

## Deploy
Upload the folder to GitHub Pages, Netlify or Vercel. For GitHub Pages: push to a repo, then Settings → Pages → deploy from `main`.

## Edit
All content is in `index.html`. Colors and fonts are in the `tailwind.config` block at the top.
